# 【Agent 结对协同与阶段交接协议 / Handoff Protocol】

## 1. 核心职责分工（Separation of Concerns）

```
+-------------------------------------------------------------+
|                      人类架构师 (Owner)                       |
|               (阶段裁决 / 设定边界 / 处理重大分歧)             |
+------------------------------+------------------------------+
                               |
                               v
+------------------------------+------------------------------+
|                   实施者 (Builder / Executor)                |
|             (Antigravity / Cursor / Aider / Gemini)         |
|  - 按照需求切片编写代码                                       |
|  - 运行本地门禁与自动化测试                                   |
|  - 起草标准化交付包 (REVIEW_REQUEST.md)                       |
|  - 调用 agent-pair-ipc 交付并挂起等待                         |
+------------------------------+------------------------------+
                               |  ^
                     IPC 通信  |  |  复核意见
                               v  |
+---------------------------------+---------------------------+
|                   审查者 (Auditor / Reviewer)                |
|                    (Claude Code / Codex)                    |
|  - 接收交付包，阅读设计与上下文                               |
|  - 独立运行测试与审计命令                                     |
|  - 审查逻辑漏洞、边界异常、代码风格、回归风险                 |
|  - 签发通过 (Sign-off) 或退回整改清单 (P0~P3)                 |
+-------------------------------------------------------------+
```

## 2. 交互守则（Collaboration Rules）

1. **单向实施、单向审查**：
   - 实施者负责写代码，不要越权充当审查者。
   - 审查者负责找问题与验证，不要直接越俎代庖替实施者改写所有业务代码，保持独立客观。

2. **零口水话契约（No Small Talk）**：
   - 所有任务与阶段交付必须沉淀为文件契约。
   - 通过 `agent-pair-ipc -f <file.md> -w` 传递，避免命令行多行转义与日志丢失。

3. **缺陷分级标准（Defect Severity Levels）**：
   - **P0 (Blocker)**：导致门禁失败、编译报错、死锁、安全漏洞、破坏核心流程。必须立即回滚或整改，不得合入。
   - **P1 (Critical)**：边界值异常、潜在内存泄漏、未处理的并发竞争。原则上必须整改后再交付。
   - **P2 (Major)**：代码重复、命名不规范、缺少单测覆盖。可记录在遗留项，下一轮解决。
   - **P3 (Minor / Nit)**：注释风格、轻微语法糖优化。建议性意见，不阻断流程。

4. **超时与故障熔断（Circuit Breaker）**：
   - 任何单次审查等待超过 300 秒无响应，实施者应中断并报警。
   - 审查回合超过 3 轮无法收敛时，必须停下向人类用户汇报，由人类仲裁。
